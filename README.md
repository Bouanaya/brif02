
## Description
Bienvenue sur ListoGo, un simple projet basé sur le web contenant la création et le développement de plusieurs pages web. Ce résumé comprend les pages suivantes :
Page d’accueil
Page Propriétés
Page du blog
Page de contact
Ce site web est basé sur des maquettes créées dans Figma et développées avec Html et CSS.

## Technologies Used

- *Desing*: Figma
- *Frontend*: HTML, CSS, JavaScript
